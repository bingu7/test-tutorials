    接口测试基础测验¶

    测验说明

    本测验用于检验接口测试教程的学习效果。共 12 道选择题，建议在学完教程后独立完成。

    📙 中级难度 ⏱ 约 20 分钟 📝 12 道选择题

    测验反馈

    提交答案后，系统会显示： - 得分和正确率 - 错题分析和薄弱知识点 - 复习建议和推荐教程 - 下一步学习建议

    HTTP 协议中，GET 请求的主要用途是？
    💡 GET 请求用于获取资源，是幂等的（多次请求结果相同）。POST 用于创建，PUT 用于更新，DELETE 用于删除。
    HTTP 状态码 200 表示什么？
    💡 200 表示请求成功。常见状态码：200 成功、201 创建成功、400 请求错误、401 未授权、404 未找到、500 服务器错误
    以下哪个 HTTP 方法是幂等的？
    💡 幂等意味着多次请求结果相同。GET、PUT、DELETE 是幂等的，POST 不是幂等的（每次请求可能创建新资源）
    接口测试中，"断言"的作用是？
    💡 断言用于验证响应结果是否符合预期，例如检查状态码、响应时间、响应体内容等
    以下哪个是常见的接口认证方式？
    💡 常见的接口认证方式包括 Token（JWT）、API Key、OAuth、Basic Auth 等。Cookie 和 Session 也可用于认证。
    JSON 格式中，以下哪个是正确的键值对？
    💡 JSON 的键和字符串值必须用双引号包裹，不能用单引号。正确格式：`{"key": "value"}`
    接口测试中，"参数化"的目的是？
    💡 参数化允许用不同的测试数据运行同一测试用例，提高测试覆盖率，减少重复代码
    以下哪个工具主要用于接口测试？
    💡 Postman 是专业的接口测试工具。Selenium 用于 UI 测试，JMeter 用于性能测试，Fiddler 用于抓包分析。
    HTTP 请求头中，Content-Type 用于指定什么？
    💡 Content-Type 指定请求体的数据格式，常见值：`application/json`、`application/x-www-form-urlencoded`、`multipart/form-data`
    接口测试中，"Mock"的作用是？
    💡 Mock 用于模拟接口响应，在依赖接口未完成或不稳定时，可以继续测试当前接口
    以下哪个 HTTP 状态码表示资源未找到？
    💡 404 表示资源未找到。400 请求错误、500 服务器错误、301 重定向
    接口自动化测试中，"数据驱动"的核心思想是？
    💡 数据驱动测试的核心思想是测试数据驱动测试执行，测试逻辑与测试数据分离，便于维护和扩展
