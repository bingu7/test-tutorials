# 模板库

模板库用于解决新手常见问题：知道要写测试文档，但不知道格式、字段和内容深度。这里的模板可以直接复制到表格、文档或项目管理工具中使用。

## 使用方式

1. 先看模板字段，理解每一列为什么存在。
2. 再看示例，模仿示例写自己的内容。
3. 最后用检查清单确认是否遗漏关键信息。

## 新手建议

- 不要为了填满模板而写废话，每个字段都要服务于沟通。
- 不确定的内容可以写“待确认”，但不要空着不管。
- 模板不是死格式，实际项目里要跟团队工具适配。
- 最重要的不是表格好看，而是别人能看懂、能复现、能决策。
