## 一、进度保存机制

### 保存方式

学习进度使用浏览器的 **localStorage** 保存，数据存储在你的浏览器中，不会上传到服务器。

### 保存内容

```json
{
    "learned": {
        "基础理论/软件测试理论基础教程": true,
        "工具操作/数据库SQL教程": true
    },
    "practice": {},
    "quiz": {
        "python-basics": {
            "score": 8,
            "total": 10,
            "percentage": 80,
            "completedAt": "2026-06-12T10:00:00.000Z"
        }
    },
    "lastUpdated": "2026-06-12T10:00:00.000Z"
}
```

### 数据说明

| 字段 | 说明 |
|------|------|
| `learned` | 教程完成状态，键为教程 ID，值为 `true` |
| `practice` | 练习完成状态（预留） |
| `quiz` | 测验结果，包含分数、总数、百分比和完成时间 |
| `lastUpdated` | 最后更新时间 |

## 二、如何使用

### 标记教程为已学习

1. 进入任意教程页面
2. 滚动到页面底部
3. 点击「标记为已学习」按钮
4. 按钮变为「✅ 已完成学习」

### 查看学习进度

1. 进入 [学习中心](../index.md)
2. 查看总体进度条
3. 查看各阶段完成度
4. 查看下一步建议

### 查看阶段详情

1. 在学习中心页面，点击阶段卡片的「查看详情」
2. 查看该阶段的教程列表
3. 勾选/取消勾选教程完成状态

## 三、注意事项

### 数据安全

- ✅ 数据只保存在你的浏览器中
- ✅ 不会上传到任何服务器
- ✅ 不需要注册登录
- ⚠️ 清除浏览器缓存后数据会丢失
- ⚠️ 更换浏览器或设备后数据不同步

### 数据备份

建议定期截图保存你的学习进度：

1. 在学习中心页面截图
2. 保存到本地
3. 如果数据丢失，可以手动恢复

### 数据恢复

如果数据丢失，可以：

1. 手动勾选已学完的教程
2. 重新完成测验
3. 使用之前的截图作为参考

## 四、常见问题

### Q: 为什么我的进度没有保存？

可能的原因：

1. 浏览器处于无痕/隐私模式（不支持 localStorage）
2. 浏览器设置禁止使用 localStorage
3. 浏览器缓存被清除

解决方案：

1. 使用正常浏览模式
2. 检查浏览器设置
3. 定期截图备份

### Q: 可以在多台设备间同步进度吗？

目前不支持多设备同步。进度只保存在当前浏览器中。

如果需要在多设备间同步，可以：

1. 在一台设备上完成学习
2. 截图保存进度
3. 在其他设备上手动勾选

### Q: 清除浏览器缓存会丢失什么？

清除浏览器缓存会丢失：

- 教程完成状态
- 测验结果
- 所有学习进度数据

不会丢失：

- 浏览器书签
- 浏览历史（除非同时清除）

### Q: 如何导出学习进度？

目前不支持直接导出。建议：

1. 在学习中心页面截图
2. 使用浏览器开发者工具查看 localStorage
3. 手动记录学习进度

## 五、技术细节

### 存储位置

- **Chrome**: `C:\Users\{用户名}\AppData\Local\Google\Chrome\User Data\Default\Local Storage`
- **Firefox**: `C:\Users\{用户名}\AppData\Roaming\Mozilla\Firefox\Profiles\{profile}\webappsstore.sqlite`
- **Edge**: `C:\Users\{用户名}\AppData\Local\Microsoft\Edge\User Data\Default\Local Storage`

### 存储限制

- localStorage 通常限制为 5-10MB
- 学习进度数据很小，不会超过限制

### 数据格式

数据使用 JSON 格式存储，可以通过浏览器开发者工具查看：

1. 按 F12 打开开发者工具
2. 切换到「Application」标签
3. 在左侧找到「Local Storage」
4. 查找 `learning-progress-2.0` 键
