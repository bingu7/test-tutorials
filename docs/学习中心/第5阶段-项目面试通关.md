# 第 5 阶段：项目与面试通关检查

!!! abstract "通关说明"
    完成项目与面试阶段后，用这个清单检查自己是否具备了项目实战能力和面试表达能力。如果 80% 以上都能做到，说明你已经具备了测试工程师的基本能力。

---

## 一、阶段目标

完成项目实战，输出作品集材料，并能进行面试表达。

---

## 二、必备能力清单

### 项目实战

- [ ] 能完成一个完整的项目实战
- [ ] 能输出测试范围和测试点清单
- [ ] 能设计完整的测试用例
- [ ] 能执行接口测试并输出报告
- [ ] 能执行 Web 自动化测试并输出报告
- [ ] 能执行性能测试并输出报告
- [ ] 能记录和跟踪缺陷
- [ ] 能输出测试报告

### 作品集产出

- [ ] 有完整的测试计划
- [ ] 有完整的测试用例
- [ ] 有缺陷报告示例
- [ ] 有接口测试报告
- [ ] 有自动化测试报告
- [ ] 有性能测试报告
- [ ] 有项目总结

### 面试表达

- [ ] 能说清楚项目的业务背景
- [ ] 能说清楚自己的测试范围和职责
- [ ] 能说清楚发现了哪些重要缺陷
- [ ] 能说清楚使用了哪些技术和工具
- [ ] 能说清楚遇到了哪些困难和解决方案
- [ ] 能说清楚项目的收获和成长

---

## 三、实操任务

### 任务 1：电商系统测试实战

- [ ] 完成需求分析和测试范围确定
- [ ] 设计完整的测试用例
- [ ] 执行接口测试并输出报告
- [ ] 记录和跟踪缺陷
- [ ] 输出测试报告

### 任务 2：接口自动化项目实战

- [ ] 搭建接口自动化框架
- [ ] 实现核心接口自动化
- [ ] 生成 Allure 测试报告
- [ ] 整理项目文档

### 任务 3：Web 自动化项目实战

- [ ] 搭建 Web 自动化框架
- [ ] 实现核心流程自动化
- [ ] 使用 Page Object 模式
- [ ] 生成测试报告
- [ ] 整理项目文档

### 任务 4：性能测试项目实战

- [ ] 设计性能测试方案
- [ ] 实现性能测试脚本
- [ ] 执行性能测试
- [ ] 分析性能瓶颈
- [ ] 输出性能测试报告

### 任务 5：CI/CD 自动化回归实战

- [ ] 配置 Jenkins 流水线
- [ ] 集成自动化测试
- [ ] 配置测试报告
- [ ] 配置失败通知

## 五、面试表达模板

### 项目介绍

```text
这个项目是一个 [业务类型] 系统，主要功能包括 [功能列表]。
我在项目中负责 [职责范围]，使用了 [技术栈] 进行测试。
```

### 测试方法

```text
我采用了 [测试策略]，覆盖了 [测试类型]。
对于核心功能，我设计了 [用例数量] 条测试用例。
对于接口测试，我使用了 [工具] 进行自动化。
```

### 缺陷案例

```text
我发现了一个 [缺陷类型] 缺陷，具体表现是 [现象]。
通过 [分析方法]，我定位到问题是 [原因]。
最终通过 [解决方案] 修复了这个问题。
```

### 技术难点

```text
在项目中，我遇到了 [困难]。
我通过 [方法] 解决了这个问题。
这个经历让我学到了 [收获]。
```

## 六、通关判断

### 通过标准

- 必备能力清单完成 80% 以上
- 实操任务全部完成
- 有完整的项目作品集
- 能进行面试表达

### 自我评估

如果你能做到以下几点，说明已经具备了测试工程师的基本能力：

1. 能完成一个完整的项目实战
2. 能输出可展示的作品集材料
3. 能用项目经验进行面试表达
4. 能说清楚"为什么这样测、怎么测、发现了什么问题"

---

## 七、下一步

如果通关检查通过，恭喜你！你已经具备了测试工程师的基本能力。

建议：

- 继续完善项目作品集
- 准备面试表达
- 学习更多高级技能（性能调优、安全渗透、测试开发）
- 关注行业动态，持续学习

如果还有薄弱点，建议：

- 回看 [项目实战](../项目实战/index.md)
- 回看 [面试专题](../面试专题/index.md)
- 完成更多项目实战
