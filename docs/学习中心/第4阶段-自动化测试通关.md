## 二、必备能力清单

### Python 基础

- [ ] 能使用变量、数据类型、运算符
- [ ] 能使用条件语句（if/elif/else）—— 根据条件执行不同代码
- [ ] 能使用循环语句（for/while）—— 重复执行代码
- [ ] 能定义和调用函数 —— 把代码封装成可复用的块
- [ ] 能使用列表、字典、元组、集合 —— 存储和管理数据
- [ ] 能使用异常处理（try/except）—— 捕获和处理错误
- [ ] 能导入和使用模块 —— 使用别人写好的代码
- [ ] 能读写文件

### 接口自动化

接口自动化是用代码自动执行接口测试，适合回归测试。

- **Requests**：Python 的 HTTP 请求库，用于发送接口请求
- **Pytest**：Python 的测试框架，用于编写和运行测试用例
- **fixtures**：Pytest 的功能，用于管理测试数据和环境（比如登录获取 Token）
- **参数化**：用不同数据运行同一个测试用例，减少重复代码
- **数据驱动**：测试数据和测试逻辑分离，方便维护
- **Allure**：测试报告工具，生成美观的报告
- **接口关联**：一个接口的输出作为另一个接口的输入（比如登录后获取 Token，用于后续请求）

需要掌握的能力：

- [ ] 能使用 Requests 库发送 HTTP 请求
- [ ] 能使用 Pytest 编写测试用例
- [ ] 能使用 fixtures 管理测试数据
- [ ] 能使用参数化实现数据驱动
- [ ] 能使用 Allure 生成测试报告
- [ ] 能使用配置文件管理环境
- [ ] 能实现接口关联（提取 Token 等）
- [ ] 能实现断言验证

### Selenium Web 自动化

Selenium 是 Web 自动化工具，模拟用户在浏览器上的操作。

- **WebDriver**：浏览器驱动，让代码能控制浏览器
- **元素定位**：找到页面上的按钮、输入框等元素
  - id：元素的唯一标识
  - name：元素的名称
  - class：元素的样式类
  - xpath：元素的路径
  - css selector：元素的 CSS 选择器
- **等待机制**：等待页面元素加载完成
  - 隐式等待：全局设置，等待指定时间
  - 显式等待：针对特定元素，等待满足条件
- **Page Object 模式**：把页面元素和操作封装成类，方便维护

需要掌握的能力：

- [ ] 能配置 WebDriver
- [ ] 能使用各种定位方式（id、name、class、xpath、css selector）
- [ ] 能实现元素操作（点击、输入、获取文本）
- [ ] 能实现等待机制（隐式等待、显式等待）
- [ ] 能实现 Page Object 模式
- [ ] 能处理弹窗、iframe、多窗口
- [ ] 能实现失败截图
- [ ] 能生成测试报告

### Playwright Web 自动化

Playwright 是微软开发的现代 Web 自动化工具，比 Selenium 更易用。

- **自动等待**：自动等待元素加载完成，不用手动写等待
- **网络拦截**：拦截和修改网络请求，用于 Mock 数据

需要掌握的能力：

- [ ] 能配置 Playwright
- [ ] 能使用各种定位方式
- [ ] 能实现元素操作
- [ ] 能实现自动等待
- [ ] 能实现网络拦截
- [ ] 能实现 Page Object 模式
- [ ] 能实现失败截图和录屏
- [ ] 能生成测试报告

### Appium App 自动化

- [ ] 能配置 Appium 环境
- [ ] 能使用各种定位方式（id、accessibility id、xpath）
- [ ] 能实现元素操作
- [ ] 能处理手势操作（滑动、长按）
- [ ] 能处理弹窗和权限
