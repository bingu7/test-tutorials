## 建议使用顺序

1. 先看 [学习路线](学习路线.md)，了解完整学习顺序。
2. 学习工具前看 [工具选型指南](工具选型指南.md)，知道每个工具解决什么问题。
3. 每完成一个阶段，用 [阶段学习检查清单](阶段学习检查清单.md) 自查。
4. 用 [章节练习与参考答案](章节练习与参考答案.md) 做练习，补齐薄弱点。
5. 最后用 [学习验收与通关路径](学习验收与通关路径.md) 判断是否达标。
