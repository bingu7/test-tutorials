# 软件测试学习路线

!!! abstract “新手导读”
    这份路线用于回答”先学什么、后学什么、学到什么程度可以进入下一阶段”。如果你是零基础或转岗学习，建议按顺序推进；如果已经有经验，可以直接跳到薄弱阶段补齐。

---

## 一、适合人群

| 人群 | 建议用法 |
|------|----------|
| 零基础入门 | 从测试理论、SQL、Linux、Git 开始，先建立工作基础 |
| 手工测试转自动化 | 重点补 Python、接口测试、Selenium、Playwright |
| 接口测试提升 | 串联 Postman、接口测试方法论、Python 接口自动化、数据库校验 |
| 测试进阶 | 补性能、安全、Docker、Jenkins、CI/CD 工程化能力 |

---

## 二、整体学习路径

```text
测试入门
  ↓
工具基础
  ↓
接口测试
  ↓
Web / App 自动化
  ↓
专项能力
  ↓
CI/CD 与工程化
  ↓
项目实战
```

学习时不要只看教程。每个阶段都应该完成练习任务，并能说清楚“为什么这样测、怎么定位问题、如何输出结果”。

---

## 三、阶段一：测试入门

**建议学时：2-3 周**（每周投入 8-10 小时）

### 学习目标

- 理解软件测试的目的、流程和常见分类。
- 能独立阅读需求并拆分测试点。
- 能编写基础测试用例和缺陷报告。

### 推荐教程

- [软件测试理论基础](基础理论/软件测试理论基础教程.md)
- [敏捷测试](基础理论/敏捷测试教程-软件测试版.md)

### 练习任务

1. 选择一个登录页面，拆分功能测试点、异常测试点和安全测试点。
2. 按等价类、边界值和场景法设计不少于 20 条测试用例。
3. 模拟 3 个缺陷，并写出缺陷标题、复现步骤、实际结果和期望结果。

### 达成标准

- 能说明测试计划、测试用例、缺陷、测试报告之间的关系。
- 能把一个简单需求拆成可执行的测试点。

---

## 四、阶段二：工具基础

**建议学时：3-4 周**（每周投入 10-12 小时）

### 学习目标

- 能使用 SQL 查询和校验业务数据。
- 能在 Linux 服务器上查看日志、进程、端口和磁盘。
- 能使用 Git 完成日常协作。
- 能用 Docker 启动基础测试环境。

### 推荐教程

- [数据库 SQL](工具操作/数据库SQL教程-软件测试版.md)
- [Linux 实用](工具操作/Linux实用教程-软件测试版.md)
- [Git 版本控制](工具操作/Git版本控制教程-软件测试版.md)
- [Docker 容器](工具操作/Docker容器教程-软件测试版.md)
- [正则表达式](工具操作/正则表达式教程-软件测试版.md)
- [网络知识](工具操作/网络知识教程-软件测试版.md)

### 练习任务

1. 写出用户表、订单表、商品表的常见查询 SQL。
2. 在 Linux 中定位一个端口占用问题。
3. 用 Git 新建分支、提交代码、解决一次模拟冲突。
4. 用 Docker 启动一个数据库或接口服务。

### 达成标准

- 能独立完成测试环境的基础排查。
- 能通过数据库和日志辅助定位问题。

---

## 五、阶段三：接口测试

**建议学时：2-3 周**（每周投入 10-12 小时）

### 学习目标

- 理解 HTTP 请求、响应、状态码、Header、Cookie、Token。
- 能使用 Postman 调试接口并编写断言。
- 能根据接口文档设计正向、异常、安全和数据一致性用例。
- 能使用 Python + Requests + Pytest 做接口自动化。

### 推荐教程

- [Postman 接口](工具操作/Postman接口测试教程-软件测试版.md)
- [Fiddler 抓包](工具操作/Fiddler抓包教程-软件测试版.md)
- [接口抓包联调实战](工具操作/接口抓包联调实战教程-软件测试版.md)
- [接口测试方法论](专项测试/接口测试完整教程-软件测试版.md)
- [Python 基础](基础理论/Python基础教程-软件测试版.md)
- [Python 接口自动化](自动化测试/Python+Requests+Allure接口自动化教程-软件测试版.md)

### 练习任务

1. 为登录、商品查询、加入购物车、创建订单设计接口用例。
2. 在 Postman 中配置环境变量、Token 提取和断言。
3. 将核心接口改写成 Pytest 自动化用例。
4. 使用数据库校验订单、库存、用户状态等数据变化。

### 达成标准

- 能从接口文档独立设计接口测试方案。
- 能说明接口自动化框架的目录结构、数据驱动方式和报告生成方式。

---

## 六、阶段四：Web / App 自动化

**建议学时：4-6 周**（每周投入 10-12 小时）

### 学习目标

- 能判断哪些场景适合自动化，哪些不适合。
- 能使用 Selenium 或 Playwright 完成 Web 核心流程自动化。
- 能理解 Page Object、等待机制、失败截图和报告。
- 能了解 Appium 移动端自动化的环境和定位方式。

### 推荐教程

- [前端基础](基础理论/前端基础教程-软件测试版.md)
- [Selenium Web 自动化](自动化测试/Selenium-Web自动化教程-软件测试版.md)
- [Playwright Web 自动化](自动化测试/Playwright自动化测试教程-软件测试版.md)
- [Appium App 自动化](自动化测试/Appium-App自动化教程-软件测试版.md)

### 练习任务

1. 自动化登录、搜索、下单前置流程。
2. 为自动化脚本增加显式等待和失败截图。
3. 用 Page Object 重构一个页面流程。
4. 对比 Selenium 和 Playwright 在等待、定位、网络拦截上的差异。

### 达成标准

- 能写出稳定的核心流程自动化脚本。
- 能解释自动化维护成本，并说明如何降低误报。

---

## 七、阶段五：专项能力

**建议学时：3-4 周**（每周投入 8-10 小时）

### 学习目标

- 能完成基础性能测试脚本设计和结果分析。
- 能识别常见 Web 安全风险。
- 能理解缓存、消息、数据库、网络对测试的影响。

### 推荐教程

- [JMeter 性能测试](专项测试/JMeter性能测试教程-软件测试版.md)
- [Web 安全测试](专项测试/Web安全测试教程-软件测试版.md)
- [Redis 与 MongoDB](工具操作/Redis与MongoDB教程-软件测试版.md)
- [网络知识](工具操作/网络知识教程-软件测试版.md)

### 练习任务

1. 对登录或查询接口做一次简单压测，并记录 TPS、响应时间和错误率。
2. 检查接口是否存在越权、弱校验、敏感信息泄露。
3. 用 Redis 或 MongoDB 校验缓存和业务数据。

### 达成标准

- 能从性能、安全、数据一致性角度补充测试风险。
- 能把发现的问题写成清晰的测试结论。

---

## 八、阶段六：CI/CD 与工程化

**建议学时：2-3 周**（每周投入 8-10 小时）

### 学习目标

- 能把自动化测试接入流水线。
- 能使用 Allure 或 HTML 报告展示结果。
- 能理解测试环境、构建、部署、回滚和通知。

### 推荐教程

- [Jenkins CI/CD](持续集成/Jenkins-CICD教程-软件测试版.md)
- [Docker 容器](工具操作/Docker容器教程-软件测试版.md)
- [Git 版本控制](工具操作/Git版本控制教程-软件测试版.md)
- [Python 接口自动化](自动化测试/Python+Requests+Allure接口自动化教程-软件测试版.md)

### 练习任务

1. 配置一次自动化测试流水线。
2. 流水线失败时保存测试报告和日志。
3. 将测试结果通知到邮件、企业微信或其他团队协作工具。

### 达成标准

- 能说明自动化测试在 CI/CD 中的位置。
- 能定位流水线失败是代码问题、环境问题还是测试脚本问题。

---

## 九、项目实战入口

学完基础教程后，建议进入 [项目实战](项目实战/index.md)：

- 先做 [电商系统测试实战](项目实战/电商系统测试实战.md)，掌握完整测试流程。
- 再做 [接口自动化项目实战](项目实战/接口自动化项目实战.md)，把 Postman、Requests、Pytest、Allure 串起来。
- 然后做 [Web 自动化项目实战](项目实战/Web自动化项目实战.md)，训练页面对象、等待、截图、报告和 CI 运行。
- 继续做 [性能测试项目实战](项目实战/性能测试项目实战.md)，训练指标、场景、压测执行和结果分析。
- 最后做 [CI/CD 自动化回归实战](项目实战/CICD自动化回归实战.md)，把自动化测试接入流水线形成持续反馈。

项目实战的目标不是背知识点，而是把需求分析、用例设计、接口验证、数据库校验、缺陷记录和报告输出串成完整工作流。
