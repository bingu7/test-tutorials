# 面试流程与谈薪

技术准备到位了，但很多人还是栽在流程和谈薪上——不是因为能力不够，而是**不知道每个环节在考什么**。

这一篇把从接到面试通知到入职的完整流程讲清楚，重点是**每一轮面试官真正想看什么**。

---

## 一、完整面试流程

```text
投递简历
   ↓
HR 初筛（电话/微信沟通 10-15 分钟）
   ↓
笔试 / 在线测评（部分公司）
   ↓
技术一面（基础 + 项目，60 分钟）
   ↓
技术二面（深度 + 场景设计，60 分钟）
   ↓
技术三面 / 主管面（架构思维 + 潜力，45 分钟）
   ↓
HR 面（稳定性 + 薪资 + 意愿，30 分钟）
   ↓
背调（部分公司）
   ↓
offer → 谈薪 → 确认入职 → 入职材料 → 入职
```

!!! abstract "不是每家公司都走完所有轮次"
    - **外包/小公司**：HR 沟通 → 技术面 1 轮 → offer（快的当天给）
    - **中型公司**：技术面 2 轮 + HR 面
    - **大厂**：技术面 3-4 轮 + HR 面 + 交叉面

    轮次越多，说明越正规。**面试轮次是判断公司正规程度的一个信号。**

---

## 二、每一轮在考什么

### 2.1 HR 初筛（10-15 分钟）

**目的**：确认你的基本信息与岗位匹配，不是技术考核。

| 常问 | 你要准备的 |
|------|-----------|
| 目前在职/离职状态？ | 实话实说，注意离职原因的表述 |
| 为什么看机会？ | 用"发展空间""技术方向"等中性理由，**不要抱怨前公司** |
| 期望薪资多少？ | 见第五节，这里要**给区间不给具体数** |
| 目前薪资多少？ | 如实说，别虚报（会背调） |
| 最快什么时候能到岗？ | 说一个合理时间 |
| 能不能接受出差/加班/驻场？ | 先问清具体情况再回答 |

!!! warning "HR 初筛的两个坑"
    **坑一：直接报最低可接受薪资**
    HR 问"期望薪资"，你答"最低 8K 也能接受"——offer 就真的定 8K 了。

    **坑二：抱怨前公司**
    "前公司管理混乱、领导不懂技术、加班太多"——HR 会想"这人来了也会这么说我们"。

### 2.2 技术一面：基础 + 项目（60 分钟）

**目的**：验证你的技术基础是否扎实，项目是否真实。

```text
时间分配（典型）：
  自我介绍         5 分钟
  项目深挖         20-25 分钟  ← 重点
  技术基础知识     20 分钟
  反问答疑         5 分钟
```

**项目深挖的考察逻辑**（面试官视角）：

| 面试官问什么 | 想验证什么 |
|--------------|-----------|
| "介绍一下这个项目" | 你能不能结构化表达 |
| "你负责哪部分" | 是真做过还是蹭项目 |
| "这个缺陷怎么定位的" | 有没有真实排查经验 |
| "为什么这么设计用例" | 有没有设计方法论 |
| "遇到什么困难" | 解决问题的能力 |
| "如果重来会怎么改进" | 反思能力 |

详细的项目表达方法见 [项目经验表达](项目经验表达.md)。

### 2.3 技术二面：深度 + 场景设计（60 分钟）

**目的**：考察技术深度和场景设计能力。

常见题型：

| 题型 | 例子 |
|------|------|
| 场景设计 | "给你一个登录功能，你怎么设计测试用例？" |
| 排查思路 | "接口返回 500，你怎么定位？" |
| 方案设计 | "要做接口自动化，你怎么设计框架？" |
| 技术对比 | "Selenium 和 Playwright 有什么区别？" |
| 难点分析 | "自动化用例不稳定，怎么排查和优化？" |

!!! tip "场景题的答题框架"
    ```
    1. 先问清约束（环境、范围、目标）
    2. 给出整体思路（分几个层面）
    3. 逐层展开具体做法
    4. 说明取舍与风险
    ```

    以"接口返回 500 怎么定位"为例：

    ```
    先确定范围：是所有接口都 500 还是单个接口？环境是测试还是线上？

    分层排查：
    - 先看请求本身：参数是否正确、是否缺少必填字段、鉴权是否过期
    - 再看服务端日志：按 traceId 检索，看是空指针、超时还是依赖服务异常
    - 然后看依赖：数据库连接是否正常、第三方服务是否可用
    - 最后看环境：配置是否正确、版本是否一致

    如果是偶发，还要关注并发、数据状态、时序问题。
    ```

### 2.4 主管面 / 三面（45 分钟）

**目的**：考察技术视野、成长潜力和团队匹配度。

| 常问 | 考察点 |
|------|--------|
| 你怎么看测试的价值？ | 对岗位的理解是否成熟 |
| 你未来 3 年想做什么方向？ | 目标是否清晰、和团队是否匹配 |
| 你怎么看待加班？ | 态度（**注意：这里也在观察你会不会直接抵触**） |
| 你怎么跟开发沟通缺陷？ | 沟通能力 |
| 如果需求时间不够，你怎么处理？ | 风险意识与取舍能力 |
| 你平时怎么学习？ | 学习能力 |

### 2.5 HR 面（30 分钟）

**目的**：确认稳定性、薪资匹配、入职意愿。

!!! warning "HR 面的真实作用"
    **HR 面不是走过场。** 技术过了但 HR 面挂掉的情况很常见，原因通常是：

    | 挂掉原因 | 具体表现 |
    |----------|----------|
    | 稳定性存疑 | 频繁跳槽、离职原因说不清 |
    | 薪资谈不拢 | 期望远超预算，且不接受调整 |
    | 意愿不明确 | 流露出"这只是备选" |
    | 态度有问题 | 抱怨前公司、对加班过度抵触 |
    | 信息不一致 | 和前几轮说的对不上 |

**HR 面高频问题及应对**：

| 问题 | 应对要点 |
|------|----------|
| 为什么离开上一家？ | 中性理由：发展空间、技术方向、通勤。**绝不说前公司坏话** |
| 为什么选我们公司？ | 说出对公司的具体了解（产品、技术栈、口碑），别只说"平台大" |
| 职业规划是什么？ | 和岗位方向一致，不要说"想转开发/转管理" |
| 能接受加班吗？ | "项目需要时可以配合，同时也关注效率提升" |
| 还有其他 offer 吗？ | 有就说有（增加议价能力），但别说具体公司名 |
| 多久能到岗？ | 说具体时间，别含糊 |

## 三、自我介绍怎么写

自我介绍是**唯一你能完全准备的环节**，必须有结构、计时 2 分钟。

### 3.1 三段式结构

```text
第一段（20 秒）：基本信息
  姓名 + 学历专业 + 测试经验年限 + 目前岗位

第二段（60 秒）：技术能力与项目重点
  核心技能栈 + 一个最能代表你的项目（背景、你的职责、结果）

第三段（20 秒）：与岗位的匹配 + 意愿
  为什么适合这个岗位 + 对这份工作的期待
```

### 3.2 示例

```text
面试官好，我叫王彬，江西财经大学软件工程专业 2026 届本科，
在恩施聪慧软件做过 6 个月的软件测试实习。

实习期间我负责电商 App 的首页秒杀、购物袋和分类三个核心模块，
设计了 150 多条覆盖满减阶梯、会员折扣叠加、库存扣减的测试用例，
累计提交有效缺陷 30 多个，修复率 95%。
其中用 JMeter 模拟过秒杀峰值 200 并发，验证了高并发下不会重复下单。

除了功能测试，我自己搭过一个接口自动化测试平台：
用 Python + Pytest + Requests 封装了统一请求基类，
解决了 Token 过期导致用例批量失败的问题，
还接了 GitHub Actions 做到提交即回归，代码 push 后自动跑全量接口用例。

我注意到贵司这个岗位强调接口测试和自动化能力，
这正好是我实习和项目里做得最多的部分，所以希望能有机会深入聊聊。
```

!!! tip "自我介绍的三个忌讳"
    - **背简历**：把简历从头念一遍，面试官会觉得你在浪费他时间
    - **说空话**："我学习能力强、抗压能力强"——没有事实支撑
    - **超时**：超过 3 分钟，面试官会打断你

## 四、反问环节怎么问

面试最后的"你有什么想问我的"，**不是客套**——问什么直接体现你的关注点。

### 4.1 分对象问不同的问题

| 问谁 | 适合问什么 | 例子 |
|------|-----------|------|
| 技术面试官 | 技术细节、团队技术栈、成长路径 | "团队的自动化测试目前到什么阶段？" |
| 主管/Leader | 团队规模、分工、考核方式 | "测试团队的分工是怎样的，会负责整个业务线吗？" |
| HR | 薪资结构、福利、流程、到岗时间 | "薪资结构是怎样的？几薪？绩效怎么算？" |

### 4.2 推荐问题清单

**技术面可以问：**
```text
- 团队目前的测试流程是怎样的？有没有自动化或平台建设的规划？
- 测试团队有多少人？测试和开发的比例大概是多少？
- 这个岗位主要负责哪块业务的测试？
- 团队在测试技术上有哪些正在推进的方向？
- 新人的成长路径是怎样的？
```

**HR 面一定要问：**
```text
- 薪资结构：基本工资 + 绩效 + 补贴？几薪？
- 绩效怎么考核？占比多少？上一年普遍能拿到多少？
- 五险一金按什么基数缴纳？
- 试用期多久？试用期薪资打折吗？
- 工作时间？加班有调休或加班费吗？
- 这个岗位是正式编制还是外包？
- 后续流程还有几轮？大概什么时候有结果？
```

!!! warning "不要问的问题"
    ```
    ❌ "贵公司是做什么的？"          → 说明你没做功课
    ❌ "加班多吗？"（单刀直入）      → 问法改成"工作时间是怎么安排的？"
    ❌ "我什么时候能升职？"          → 太早
    ❌ "面试结果怎么样？"            → HR 不会当场告诉你
    ```

### 4.3 "薪资结构"为什么必须问

!!! abstract "一个真实案例"
    ```
    offer：月薪 12K
    实际到手：基本工资 6K + 绩效 6K
    绩效按季度考核，实际平均发放 70%
    → 实际月均收入 ≈ 6K + 6K × 0.7 = 10.2K
    ```

    **名义薪资和实际到手可能差 20-30%。** 必须问清：
    - 基本工资和绩效各占多少
    - 绩效的实际发放比例
    - 年终奖是几个月，有没有发放条件（如"在职满 1 年"）
    - 补贴是否计入社保基数

## 五、谈薪

### 5.1 谈薪的基本原则

```text
原则一：先给区间，后给具体数
原则二：不主动报最低可接受值
原则三：有 offer 是最大的筹码
原则四：薪资是谈出来的，不是给的
```

### 5.2 各环节的应对

| 环节 | 问题 | 应对 |
|------|------|------|
| HR 初筛 | 期望薪资？ | **给区间**："我了解到这个岗位的市场范围是 X-Y，考虑到我的经验，期望是 Y 左右。" |
| 技术面 | 期望薪资？ | "这块我和 HR 聊更合适，先聊聊技术。"（技术官通常不管薪资） |
| HR 面 | 期望薪资？ | 见下方 |
| offer | 薪资是 XX | 见下方谈判 |

### 5.3 报价策略

!!! warning "不要直接报"最低可接受""
    ```
    ❌ HR：期望多少？
       你：最低 8K 也能接受。
       → offer 就是 8K。

    ✅ HR：期望多少？
       你：我了解到这个岗位和我的经验匹配，
          期望在 11-13K 之间，具体可以根据整体 package 来看。
    ```

**区间怎么定：**

```text
先调研市场价（BOSS/猎聘看同城同岗位薪资范围）
   ↓
你的报价区间 = 市场价中位数 ~ 中位数 + 15%
   ↓
心里底线 = 市场价中位数下浮 10%

例如：市场范围 9-14K，中位数 11K
  报价区间：11-13K
  心理底线：10K（低于这个不接）
```

### 5.4 offer 谈判

**情况一：对方给到你的期望区间内**

```text
不要立刻答应，也不要立刻砍价。
可以说："感谢您的认可。这个薪资基本符合我的预期，
         我想了解一下整体的薪资结构和福利情况，
         再综合考虑后给您答复。"
```

**情况二：对方给的低于期望**

| 你的筹码 | 谈判话术 |
|----------|----------|
| 有其他 offer | "我目前也拿到了一个 XX 的 offer，薪资是 XX。相比之下我更看好贵司的技术方向，如果能到 XX，我会优先选择这里。" |
| 无其他 offer | "考虑目前的能力和对岗位的匹配度，希望能调整到 XX。如果确实有预算限制，能否通过试用期后调薪或绩效部分来平衡？" |

**情况三：对方说"预算固定"**

可以争取：
```text
- 试用期不打折
- 缩短试用期（3 个月 → 2 个月）
- 明确转正调薪机制和时间点
- 补贴、餐补、交通补助
- 年终奖月数
- 更高级别的职级（影响后续涨薪基数）
```

### 5.5 谈薪的四个忌讳

!!! danger "不要犯这些错"
    **一、虚报当前薪资**
    背调会查（社保记录、工资流水），查出直接撤销 offer，且是诚信问题。

    **二、用"不来"威胁**
    "不给到 XX 我就不来"——除非你真有其他 offer，否则对方直接放弃你。

    **三、只看月薪**
    12K × 12 薪 = 14.4 万，10K × 15 薪 = 15 万。
    **要看年包**：月薪 × 薪数 + 年终奖 + 补贴。

    **四、答应后又反悔**
    接受了 offer 再反悔（"拒 offer"）在行业内会被记录，部分公司共享黑名单。**接受前想清楚。**

## 六、offer 对比

拿到多个 offer 时，别只看薪资。

### 6.1 对比维度

| 维度 | 要看清什么 |
|------|-----------|
| **薪资** | 年包（月薪 × 薪数 + 奖金 + 补贴），不只看月薪 |
| **社保公积金** | 缴纳基数（按最低基数交是损失）、比例 |
| **工作时间** | 每天几点到几点、大小周还是双休、加班频率 |
| **通勤** | 单程时间（超过 1 小时会显著影响生活质量） |
| **技术成长** | 有没有自动化/平台建设、技术栈是否主流 |
| **业务方向** | 业务是否有前景、是否能积累可迁移经验 |
| **公司稳定性** | 融资阶段、裁员传闻、业务收缩 |
| **直属领导** | 面试时的沟通感受（很重要但常被忽略） |
| **编制性质** | 正式还是外包（影响一切） |

### 6.2 决策优先级

!!! abstract "3 年内的优先级建议"
    ```
    技术成长 > 薪资 > 公司平台 > 通勤 > 其他

    理由：前 3 年是能力积累期。多拿 1K 但技术停滞，
         3 年后跳槽时议价能力反而更低。
         技术成长快的团队，2-3 年后薪资能翻倍。
    ```

    **但有两个例外**：
    - 薪资差距超过 40%（影响生活质量和心态）
    - 明显的外包 vs 正式编差异（优先正式编）

## 七、背调与入职

### 7.1 背调会查什么

| 项目 | 说明 |
|------|------|
| 学历 | 学信网验证，**造假必被查出** |
| 工作经历 | 起止时间、职位、离职原因 |
| 薪资 | 部分公司要求提供工资流水 |
| 工作表现 | 联系前直属领导（一般需你授权） |
| 犯罪记录 | 部分岗位需要 |

!!! warning "背调的雷区"
    - **别为了接 offer 而隐瞒**：履历有空窗期要主动说明
    - **别虚报职级/职责**：前领导一句话就能验证
    - **离职原因要一致**：和 HR 面说的保持一致
    - **社保记录是铁证**：虚报工作时长容易被查出来

### 7.2 入职准备

```text
材料清单（提前准备）：
  身份证原件及复印件
  学历证、学位证原件及复印件
  学信网学历验证报告
  离职证明（上一家公司开具，重要！）
  体检报告（部分公司要求指定医院）
  银行卡、一寸照片若干
  社保公积金转移材料（如需）
```

!!! tip "离职证明要提前拿"
    从上家离职时**一定要拿到离职证明**，很多公司入职必须提供。
    如果原公司拖延，提前沟通，别等到入职前一天才着急。

### 7.3 三方与实习（应届生）

```text
三方协议：校招签约后签订，涉及违约金条款，签字前看清
实习转正：实习期表现好可直接转正，注意问清转正标准
应届生身份：部分城市落户、政策优惠依赖应届生身份，注意时效
```

## 八、全流程自查清单

**面试前**
- [ ] 自我介绍已写好并计时（2 分钟内）
- [ ] 项目讲解已准备 2-3 个"难点+解决方案"故事
- [ ] 已了解目标公司（产品、技术栈、近期动态）
- [ ] 备好可展示的项目材料（用例、报告、代码仓库）
- [ ] 准备了 5 个反问问题

**面试中**
- [ ] 自我介绍有结构不超时
- [ ] 项目讲解有背景、职责、动作、结果
- [ ] 遇到不会的坦诚说明，不硬编
- [ ] 反问环节问了技术栈和团队情况

**面试后**
- [ ] 立刻复盘记录被问到的问题
- [ ] 标记答不好的问题并补课
- [ ] 更新到投递记录表

**HR 面 / offer**
- [ ] 已问清薪资结构（基本+绩效+薪数）
- [ ] 已问清五险一金缴纳基数
- [ ] 已问清是正式编还是外包
- [ ] 已问清试用期时长与薪资折扣
- [ ] 已确认到岗时间和后续流程
- [ ] 对比了多个 offer 的年包和技术成长
