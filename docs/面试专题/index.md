## 面试回答原则

- 先给结论，再补例子。
- 不会的不要硬编，可以说“我了解到的做法是”。
- 尽量从项目场景回答，不要只背概念。
- 说清楚你做了什么、为什么这么做、结果如何。
- 遇到工具题，要说明使用场景，而不是只说功能菜单。

## 回答结构

```text
结论
  -> 适用场景
  -> 项目例子
  -> 风险或注意点
```

例如问“你怎么设计登录测试用例”，不要只说“正常和异常”。更好的回答是：

```text
我会从正常登录、参数校验、账号状态、安全限制和会话保持几个角度设计。
比如正常账号密码登录成功；密码错误、手机号为空、格式错误；禁用账号和锁定账号；连续输错密码是否锁定；登录后刷新页面是否保持登录，退出后是否不能访问首页。
如果做接口测试，还会校验 token、业务码、失败次数和锁定状态。
```
