??? note "为什么只有这几道题？"
    能自动判分的前提是**答案有客观对错**——像「统计用例结果」「从日志提取字段」「换算性能指标」这类任务，结果可以用断言验证。

    而站内另外 39 篇教程的动手任务，多数是**判断力型**任务（例如「这是产品缺陷还是需求问题」「这条流水线为什么形同虚设」「该不该放弃 UI 自动化」）。它们的答案需要结合上下文论证，一味用选择题判分反而会退化成背答案，所以保持开放式，用每篇末尾的折叠参考答案供对照。

    → 查看全部动手任务：[学习路线](学习路线.md) 或直接在各教程末尾找到「动手任务」小节。

## 怎么用

1. **点上方表格里的教程名**进入对应教程，页面里就有练习框（含「动手任务」小节的页面往下滚即可看到）。
2. 在练习框里写代码，点「**运行并判分**」。
3. 卡住了可以点「**看提示**」——只给方向，不给答案；答错时也会针对失败项给出提示。
4. **全部检查项通过**才算完成，同时会自动把该教程标记为「已学习」。
5. 代码会**自动保存**在浏览器里，换页或关闭再回来都还在。

!!! tip "关于状态列"
    - **未做**：还没运行过
    - **N/M**：运行过但没全过，N 是通过的检查项数
    - **✅ 已通过**：全部检查项通过

    只有「已通过」才计入学习进度的阶段完成度。
