## 💡 使用建议

!!! tip "学习建议"

    1. **按阶段顺序学习**，不要跳过基础直接学自动化
    2. **边学边练**，学完基础后进入项目实战，把知识串成完整流程
    3. **善用搜索**，右上角搜索框支持全文检索
    4. **收藏常用命令**，把高频命令记到自己的笔记里

!!! warning "注意事项"

    - 教程中的代码示例基于特定版本，实际使用时注意版本兼容
    - 测试纪律：禁止在生产环境执行未授权的操作
    - 敏感信息（密码、Token）不要硬编码，用环境变量管理
