### 新增
- **5 份项目实战测验**：电商系统测试实战、接口自动化项目实战、Web 自动化项目实战、性能测试项目实战、CI/CD 自动化回归，每份 12 道选择题，测验总数由 33 份增至 38 份；5 篇实战教程结尾同步补"阶段测验 + 通关检查"入口，至此全部教程都有专属测验
- **24 份阶段测验**：Git、Docker、JMeter 性能、Web 安全、Python 接口自动化、Selenium、Postman、Fiddler、Charles、JavaScript、TypeScript、ISTQB 术语、测试金字塔、测试用例设计、前端基础、探索式测试、敏捷测试、正则表达式、Redis 与 MongoDB、接口抓包联调、AI 辅助测试、测试左右移、移动端专项、Appium，测验总数由 9 份增至 33 份，每份 12 道选择题并带错题分析与复习建议
- **教程补"阶段测验"入口**：13 篇此前没有测验的教程尾部新增测验入口，配合原有的"推荐下一步 + 通关检查"形成"学 → 测 → 通关"闭环；至此除项目实战外，全部教程都有专属测验

- **社交分享卡片**：开启 Material social 插件，自动为每页生成 og:image 分享卡片（1200×630），在微信/知乎等平台转发时显示标题与配图

### 改进
- **第 2 阶段口径统一**：接口抓包联调实战、Redis 与 MongoDB 两篇教程与对应测验由第 3 阶段移回第 2 阶段，学习路线、学习验收与通关路径、首页阶段导航、学习进度配置与第 2/3 阶段通关检查同步调整，消除"页内通关检查写第 2 阶段、学习路线归第 3 阶段"的分歧

- **Markdown 渲染修复**：启用 `md_in_html` 扩展，修复 10 篇教程结尾"下一步建议"区块内的标题、任务清单、链接全部显示为原始 Markdown 源码的问题

## 版本说明

### 版本号规则

- **主版本号（MAJOR）**：不兼容的 API 修改
- **次版本号（MINOR）**：向下兼容的功能性新增
- **修订号（PATCH）**：向下兼容的问题修正

### 变更类型

- **新增（Added）**：新功能
- **变更（Changed）**：对现有功能的变更
- **弃用（Deprecated）**：即将移除的功能
- **移除（Removed）**：已移除的功能
- **修复（Fixed）**：任何 bug 修复
- **安全（Security）**：安全相关的变更

### 更新频率

- **主版本**：每季度发布一次（重大更新）
- **次版本**：每月发布一次（新功能）
- **修订版本**：每周发布（bug 修复和小改进）

### 如何获取更新

1. **GitHub 仓库**：Watch 仓库获取更新通知
2. **在线文档**：访问 [https://bingu7.github.io/test-tutorials/](https://bingu7.github.io/test-tutorials/)
3. **RSS 订阅**：订阅文档更新（如果支持）

### 如何贡献

1. Fork 仓库
2. 创建功能分支
3. 提交 Pull Request
4. 等待审核和合并
