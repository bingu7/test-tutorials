    第 2 阶段：工具实战通关检查¶

    通关说明

    完成工具实战阶段后，用这个清单检查自己是否掌握了测试必备工具。如果 80% 以上都能做到，可以进入第 3 阶段。

    一、阶段目标¶

    掌握 SQL、Linux、Git、Postman、Fiddler、网络知识等高频工具。

    二、必备能力清单¶

    数据库 SQL¶

    SQL 是操作数据库的语言，测试人员用它来查询和校验业务数据。

    • 能使用 SELECT 查询数据（从表中获取数据）
    • 能使用 WHERE 筛选条件（比如"只查状态为已支付的订单"）
    • 能使用 JOIN 关联多表查询（把用户表和订单表关联起来查）
    • 能使用 GROUP BY 分组统计（比如"按用户分组统计订单数量"）
    • 能使用 ORDER BY 排序（比如"按时间倒序排列"）
    • 能使用聚合函数（COUNT 统计数量、SUM 求和、AVG 求平均、MAX 求最大值、MIN 求最小值）
    • 能使用子查询（在一个查询里面嵌套另一个查询）
    • 能理解 NULL 值的处理（NULL 表示"没有值"，不能用 = 判断，要用 IS NULL）

    Linux 实用¶

    Linux 是服务器操作系统，测试人员用它来查看日志、排查问题。

    • 能使用基本文件操作命令（ls 列出文件、cd 进入目录、pwd 显示当前路径、mkdir 创建目录、rm 删除、cp 复制、mv 移动）
    • 能使用文件查看命令（cat 查看整个文件、head 查看开头、tail 查看结尾、less/more 翻页查看）
    • 能使用 grep 搜索日志（在大量日志中搜索关键字，比如搜索"ERROR"）
    • 能使用 ps、top 查看进程（进程是正在运行的程序，用它查看服务是否启动）
    • 能使用 netstat、lsof 查看端口（端口是程序通信的入口，比如 MySQL 默认用 3306 端口）
    • 能使用 df、du 查看磁盘（查看磁盘空间是否满了）
    • 能使用 chmod 修改权限（控制谁能读/写/执行文件）
    • 能使用 tail -f 实时查看日志（持续显示日志的最新内容，用于实时监控）

    Git 版本控制¶

    • 能使用 git clone 克隆仓库
    • 能使用 git add、git commit 提交代码
    • 能使用 git push、git pull 同步代码
    • 能使用 git branch 创建和切换分支
    • 能使用 git merge 合并分支
    • 能解决简单的合并冲突
    • 能使用 git log 查看提交历史

    Docker 容器¶

    Docker 是容器化工具，可以快速搭建测试环境，不用手动安装各种软件。

    • 镜像：类似安装包，包含了程序运行所需的所有文件
    • 容器：类似安装好的程序，从镜像创建，可以启动、停止、删除

    需要掌握的能力：

    • 能使用 docker pull 拉取镜像（下载安装包）
    • 能使用 docker run 启动容器（从安装包启动程序）
    • 能使用 docker ps 查看容器（查看正在运行的程序）
    • 能使用 docker logs 查看容器日志（查看程序运行记录）
    • 能使用 docker stop、docker rm 停止和删除容器
    • 能使用 docker-compose 启动多容器服务（一次启动多个相关程序）
    • 理解镜像和容器的区别

    Postman 接口¶

    Postman 是接口调试工具，用于向服务器发送请求并查看响应。

    • GET 请求：获取数据，比如查询用户信息
    • POST 请求：提交数据，比如登录、创建订单
    • PUT 请求：更新数据，比如修改用户信息
    • DELETE 请求：删除数据
    • 请求头：请求的附加信息，比如 Token、Content-Type
    • 请求体：POST/PUT 请求携带的数据
    • 断言：检查响应是否符合预期的代码

    需要掌握的能力：

    • 能创建和发送 GET、POST、PUT、DELETE 请求
    • 能设置请求头、请求体、查询参数
    • 能使用环境变量管理不同环境（测试环境、生产环境用不同地址）
    • 能使用 Pre-request Script 提取 Token（在请求前自动获取登录凭证）
    • 能使用 Tests 编写断言（检查返回结果是否正确）
    • 能使用 Collection Runner 批量执行（一次运行多个测试用例）
    • 能导出和导入 Collection（备份和分享测试集合）

    Fiddler 抓包¶

    • 能配置 Fiddler 代理
    • 能抓取 HTTP/HTTPS 请求
    • 能查看请求和响应的详细信息
    • 能使用过滤器筛选请求
    • 能使用断点修改请求和响应
    • 能分析接口参数和返回值

    网络知识¶

    网络知识帮助理解接口通信原理，是接口测试的基础。

    • HTTP：网页传输协议，浏览器和服务器之间通信的方式
    • 状态码：服务器返回的数字代码，表示请求结果
    • 200：成功
    • 400：请求错误（参数有问题）
    • 401：未登录
    • 403：无权限
    • 404：找不到资源
    • 500：服务器错误
    • Cookie：浏览器保存的小数据，比如登录状态
    • Session：服务器保存的用户信息，和 Cookie 配合使用
    • Token：登录凭证，比 Session 更灵活，常用于移动端和接口认证
    • HTTPS：加密的 HTTP，数据传输更安全
    • DNS：把网址（如 baidu.com）转换为 IP 地址的服务

    需要掌握的能力：

    • 能解释 HTTP 请求方法（GET、POST、PUT、DELETE）
    • 能解释 HTTP 状态码（200、301、302、400、401、403、404、500）
    • 能解释 Cookie 和 Session 的区别
    • 能解释 Token 的作用
    • 能解释 HTTPS 的加密原理
    • 能解释 DNS 解析过程

    三、实操任务¶

    任务 1：SQL 查询¶

    • 查询用户表中所有活跃用户
    • 查询订单表中最近 7 天的订单
    • 统计每个用户的订单数量
    • 查询订单金额大于 1000 的订单
    • 关联用户表和订单表查询

    任务 2：Linux 操作¶

    • 在 Linux 中查看最近 100 行错误日志
    • 查找占用 8080 端口的进程
    • 查看磁盘使用情况
    • 实时查看应用日志

    任务 3：Git 操作¶

    • 新建分支开发功能
    • 提交代码并推送到远程
    • 合并分支并解决冲突

    任务 4：Docker 操作¶

    • 使用 Docker 启动 MySQL 数据库
    • 使用 Docker 启动一个 Web 应用
    • 查看容器日志排查问题

    任务 5：Postman 操作¶

    • 调试登录接口并获取 Token
    • 使用 Token 调用需要认证的接口
    • 编写断言验证接口返回
    • 批量执行测试用例

    任务 6：Fiddler 抓包¶

    • 抓取登录请求分析参数
    • 抓取接口请求查看返回值
    • 使用断点修改请求参数
